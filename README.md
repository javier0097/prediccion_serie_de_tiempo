### Ejecucion del notebook
Para ejecutar el notebook "prediccion de ingresos.ipynb", es necesario que este archivo como el archivo "lecturas.xlsx" 
se encuentre en la misma ubicacion. En la segunda celda del notebook se verifica la ubicacion del proyecto, verificar que 
el archivo lecturas.xlsx este en la misma ubicacion.

Este notebook puede ser abierto tanto en el Google Colab o en Jupyter Notebook, pero se recomienda que se lo ejecute en
Jupiter, ya que fue desarrollado en el mismo. Luego de abrir el notebook en Jupiter o en Colab, simplemente ejecutar
todas las celdas en orden secuencial.
